# CampusTrace MVP

Одностраничный прототип визуального паспорта университета для кейса Visual Campus. Вводите название, выбирайте точную организацию, смотрите лицензированные изображения с первоисточниками и уровнем уверенности. Пустые разделы показываются честно. Две особенности: паспорт доказательств каждого кадра и сравнение полноты источников двух вузов.

Интерфейс устроен как исследовательский атлас: поиск сворачивается после загрузки профиля, карта становится главным рабочим блоком, восемь разделов показывают число доступных кадров, а автор и лицензия видны на каждой карточке. На узком экране фильтры прокручиваются горизонтально. В паспорте материала доступны исходная страница, даты и причины отбора.

## Быстрый запуск

Требуется Python 3.11+ и доступ к интернету для свежей сборки профиля.

```bash
cd campustrace-mvp
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# В .env замените your-email@example.com на контакт оператора приложения.
set -a
source .env
set +a
uvicorn app.main:app --host 127.0.0.1 --port 8765
```

Откройте <http://127.0.0.1:8765>. Документация API: <http://127.0.0.1:8765/docs>. Проверка сервера: `curl http://127.0.0.1:8765/api/health`.

Для быстрой демонстрации ищите `Nazarbayev University`. На чистой базе поиск и сборка профиля сделают запросы к внешним сервисам, затем профиль кэшируется на сутки. Для `Astana IT University` намеренно видны пробелы в галерее: это показывает отсутствие подтверждённых открытых материалов, а не ошибку интерфейса.

В распакованном архиве база создаётся с нуля; локальная рабочая папка после наших проверок может содержать автоматически собранный кэш.

## Включённые источники

| Источник | Назначение | Условия |
|---|---|---|
| ROR API v2 | Идентичность, поиск, алиасы, география | Без ключа |
| Wikidata | Категория Commons `P373`; датированное число студентов `P2196` | Без ключа |
| Wikimedia Commons | Файлы и метаданные прав | Без ключа; нужен корректный User-Agent |
| SQLite | Кэш профилей, материалов и событий источников | Файл `data/campustrace.sqlite3` |
| OpenAlex | Ряд публикаций по годам | Обогащение, отдельный запрос |
| Nominatim | Кандидатная точка карты | 1 запрос/сек на процесс, укажите контакт в User-Agent |
| Open-Meteo | Текущая погода города | Только городской контекст |
| Flickr | Дополнительные снимки с разрешёнными лицензиями | `FLICKR_API_KEY` |
| Brave Search | Ссылки на официальные страницы | `BRAVE_API_KEY` |
| YouTube Data API | Ролики проверенного официального канала | `YOUTUBE_API_KEY` и `OFFICIAL_YOUTUBE_CHANNELS_JSON` |
| PullPush Reddit index | Свежие ссылки на индексируемые публичные обсуждения | Без ключа; выдача неполная |
| Groq API | Сводка только по найденным постам, без генерации источников | `GROQ_API_KEY` |

Пример карты каналов: `OFFICIAL_YOUTUBE_CHANNELS_JSON='{"052bx8q98":"UC..."}'`. Значение `UC...` замените на **проверенный** ID официального канала. Никакие ключи в репозиторий не добавляйте. Маршрутные изохроны подключены через openrouteservice и требуют `OPENROUTESERVICE_API_KEY`. PostgreSQL, CV-модель и полный импорт студенческой статистики остаются следующими этапами.

## Основные маршруты

```text
GET /api/search/suggest?q=НУ
GET /api/atlas/052bx8q98
GET /api/atlas/052bx8q98/isochrone?mode=walking&minutes=15
GET /api/institutions?q=Nazarbayev%20University
GET /api/profiles/052bx8q98
GET /api/profiles/052bx8q98?refresh=true
GET /api/assets/{asset_id}
GET /api/profiles/052bx8q98/extras
GET /api/profiles/052bx8q98/student-voices
GET /api/compare?left=052bx8q98&right=05jnvbc31
GET /api/integrations
GET /api/health
```

Профиль собирается с лимитом 28 секунд. При ошибке или таймауте обновления возвращается предыдущая версия, если она есть. `generated_at`, `from_cache`, `elapsed_ms`, `warnings` и `source_events` помогают понимать свежесть и проблемы источников.

## Как работает отбор

1. Поиск ROR выводит варианты с городом и страной; первый результат не выбирается автоматически.
2. Из ROR берётся Wikidata ID; Commons category и подходящие подкатегории дают основные кандидаты. Поиск Commons помогает, если категория пуста.
3. Отдельный поток ищет снимки города. Такой кадр имеет статус `city_context` и не объявляется кампусом.
4. Файлы без указанной лицензии, логотипы, документы и явные посторонние сюжеты отсеиваются. Проверяется заголовок и контекст категории.
5. Дубли удаляются по SHA-1 и perceptual hash миниатюры. Статус `probable` означает связь с университетом, но не доказанный адрес.
6. На странице видны число кандидатов, число допущенных метаданных, уникальных кадров и итоговая галерея.

Это консервативный MVP. Автоматический текстовый анализ заголовков не распознаёт все языки и может ошибаться. Категория Commons и подпись иногда происходят от одного автора; независимым подтверждением они не считаются. Для публичного запуска нужна дополнительная выборочная ручная проверка и механизм исправления.

## Три визуализации

- Полнота категорий: материалы по кампусу, общежитию, аудиториям, библиотеке, городу, спорту, лабораториям и студенческой жизни.
- Воронка отбора: кандидаты → материалы с метаданными и лицензией → уникальные → опубликованные в профиле.
- Динамика публикаций OpenAlex: годы 2016–2025; подпись поясняет, что это не число студентов и не оценка преподавания. Отдельным числом показывается Wikidata `P2196` только при наличии даты и ссылки на запись.

## Тесты и ручная проверка

```bash
python -m unittest discover -s tests -v
python -m compileall -q app
node --check static/app.js
```

Живой сборщик проверен на Nazarbayev University, Astana IT University, Al-Farabi Kazakh National University и University of Tartu; браузерный smoke test выполнен для загрузки профиля Nazarbayev University. Выдача зависит от доступности и изменений внешних источников. Для воспроизведения на новой машине используйте `?refresh=true` и сверяйте время сборки/предупреждения. После серии запросов Commons/Wikidata возможен `429`; при этом сохранённый профиль остаётся доступен.

## Права, карты и пределы

Каждая картинка ведёт на страницу исходного файла и показывает автора/лицензию. Для открытых лицензий проверяйте конкретные условия атрибуции и производных работ. Поисковая ссылка на официальный сайт **не** разрешает копировать оттуда фотографию. Кандидат Nominatim требует подтверждения; координата в ROR может относиться к городу, а не к конкретному корпусу. Число публикаций OpenAlex не является студенческой статистикой. Для нагрузочного production режима нужны общий rate limiter, PostgreSQL, очередь и наблюдаемость.

Исходная документация: [ROR](https://ror.readme.io/docs/rest-api), [Wikimedia Commons reuse](https://commons.wikimedia.org/wiki/Commons:Reusing_content_outside_Wikimedia), [Nominatim policy](https://operations.osmfoundation.org/policies/nominatim/), [OpenAlex](https://docs.openalex.org/api-entities/institutions), [Open-Meteo](https://open-meteo.com/en/docs).


## Интерактивный атлас — обновление сентября 2026

Дизайн доработан GPT-6 Astra с `design-taste-frontend`. Промпт и его источники OpenAI сохранены рядом с проектом в `CAMPUS_TRACE_ASTRA_PROMPT.md`.

- MapLibre GL JS 5.8.0 поставляется локально; базовая карта OpenFreeMap загружается по сети без API-ключа. Доступны глобус, перелёт к кампусу, масштабирование и отдельная ссылка Google Maps. Это внешняя ссылка, не встроенная Google Maps API.
- NU: OSM-граница way 424894683, 12 учебных корпусов, 6 общежитий, 7 остановок по подписанным блокам.
- UPenn: OSM relation 2594845 с 21 участком, 30 учебных корпусов и 33 общежития в загруженной центральной области, 7 остановок. Это неполный реестр зданий.
- AITU: именованная точка OSM node 10575843769, сопоставленная с адресом C1. Граница здания и общежития не утверждаются.
- Геокадры получают координаты через MediaWiki GeoData. Маркер различает место камеры и место объекта. Наличие геотега не повышает автоматически достоверность принадлежности снимка университету.
- Прогулка переключает реальные точки и источники. Дорожная траектория между остановками не построена. Изохроны рассчитываются отдельным серверным запросом openrouteservice при наличии ключа.
- Подсказки понимают локальные сокращения и кириллицу; остальные запросы идут в ROR. Число локальных синонимов пока ограничено тремя показательными вузами.
- В SQLite идентификатор материала уникален в пределах профиля; один Commons-файл может корректно принадлежать двум профилям.

OSM-слои — снимок открытой карты, полученный 16 сентября 2026. Они подтверждают наличие объектов в OSM, а не официальный статус помещений. Вся геометрия имеет ссылки на исходные объекты и атрибуцию ODbL. Для новых вузов без проверенных данных карта показывает точку города с соответствующей подписью.

## Публичные отзывы и Groq

Кнопка «Исследовать отзывы» выполняет отдельный запрос только после действия пользователя. Сначала сервис ищет небольшой набор индексируемых публичных Reddit-публикаций по вузу, жилью и кампусу; затем Groq получает лишь эти короткие фрагменты и формирует нейтральную сводку на русском. Ссылки на найденные публикации остаются на странице. Если Groq недоступен или достиг квоты, первоисточники всё равно отображаются без искусственной сводки. Это не рейтинг и не выборка мнений всех студентов.

Документация карты: [OpenFreeMap](https://openfreemap.org/quick_start/), [MapLibre](https://maplibre.org/maplibre-gl-js/docs/), [openrouteservice](https://openrouteservice.org/dev/), [MediaWiki GeoData](https://www.mediawiki.org/wiki/Extension:GeoData/en).
